# 🚗 Highway Racer

A simple browser driving game made with **HTML, CSS and JavaScript**.

## 🎮 Controls

- Keyboard: `←` / `→`
- Keyboard: `A` / `D`
- Mobile: use the left/right buttons

## 🚀 Run locally

Open `index.html` in your browser.

## 🌐 GitHub Pages

1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Open **Settings → Pages**.
4. Select your main branch and root folder.
5. Save and open the generated GitHub Pages URL.

Enjoy! 🏁
